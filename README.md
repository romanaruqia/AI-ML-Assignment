# AI-ML-Assignment
Time series prediction using LSTM/GRU on NIFTY stock data from NSE India on Nestle

## Dataset
NIFTY stock data (NESTLEIND)

## Models Used
- LSTM
- GRU

## Tasks Performed
- 5→5 prediction
- 10→5 prediction
- Metrics: MSE, RMSE, MAE

## Results
Both models were trained and compared. GRU/LSTM performed better based on RMSE.
